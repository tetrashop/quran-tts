# 🕌 تلاوت قرآن با شبیه‌سازی صدا (Voice Cloning)

پروژه‌ای متن‌باز برای تولید تلاوت آیات قرآن با کلون‌سازی صدا با استفاده از مدل **XTTS-v2** و رابط کاربری **Gradio**.  
با این پروژه می‌توانید متن یک آیه (با اعراب کامل) و یک فایل صوتی ۶ تا ۳۰ ثانیه‌ای از یک قاری را وارد کنید تا همان آیه با همان سبک و لحن قاری تلاوت شود.

---

## 🎯 اهداف و انگیزه
- دسترسی آسان به تلاوت شخصی‌سازی‌شده برای آموزش، تحقیق و استفاده‌ی عمومی.
- استفاده از فناوری متن‌باز برای شبیه‌سازی صدا بدون نیاز به آموزش جداگانه.
- ارائه‌ی یک راه‌حل رایگان و قابل اجرا روی فضای ابری (Hugging Face Spaces).

---

## 🧠 پیشینه و مبانی نظری

### شبیه‌سازی صدا (Voice Cloning)
فرآیند تبدیل متن به گفتار (TTS) با استفاده از یک نمونه‌ی کوتاه از صدای هدف. مدل‌های پیشرفته مانند XTTS از معماری Transformer و رمزگذار صوتی (vocoder) برای تولید گفتار طبیعی با حفظ ویژگی‌های گوینده استفاده می‌کنند.

### مدل XTTS-v2
- توسعه‌یافته توسط **Coqui AI**.
- یک مدل چندزبانه‌ی **Zero-shot** که تنها با چند ثانیه صدای مرجع می‌تواند به همان زبان صحبت کند.
- از اعراب‌گذاری (diacritics) در زبان عربی پشتیبانی می‌کند که برای تلاوت قرآن ضروری است.
- حجم مدل: حدود ۱.۸۷ گیگابایت.
- قابل اجرا روی CPU و GPU.

### چالش‌های تلاوت قرآن
- نیاز به رعایت قواعد تجوید (کشیدگی‌ها، غنه، تفخیم و ...).
- حساسیت بالا به اعراب‌گذاری کامل (تشکیل).
- مدل‌های عمومی TTS معمولاً برای تلاوت حرفه‌ای بهینه‌سازی نشده‌اند.

---

## 🏗️ معماری و پیاده‌سازی

### اجزای اصلی
- **Docker**: برای ایجاد محیط ایزوله و قابل تکرار با Python 3.11.
- **Gradio**: رابط کاربری وب با دو ورودی (متن آیه و فایل صوتی) و دو خروجی (وضعیت و فایل صوتی تولیدشده).
- **کتابخانه‌های اصلی**: `TTS`, `gradio`, `soundfile`, `torch`, `transformers`.
- **Hugging Face Spaces**: میزبانی رایگان با قابلیت اجرای Dockerfile.

### دیاگرام ساده
```

کاربر ── (متن + فایل صوتی) ──> Gradio Interface ──> TTS (XTTS-v2)
│
└──> فایل صوتی تلاوت

```

---

## ✨ ویژگی‌ها
- پشتیبانی از متن عربی با اعراب کامل.
- شبیه‌سازی صدا تنها با یک نمونه‌ی ۶ ثانیه‌ای.
- اجرا روی CPU رایگان (با زمان ۲-۵ دقیقه) یا GPU (چند ثانیه).
- رابط کاربری ساده و واکنش‌گرا.
- امکان استفاده به صورت **API** (برای بات تلگرام و غیره).
- کد کاملاً متن‌باز با مجوز MIT.

## 🚀 نصب و اجرا

### ۱. پیش‌نیازها
- پایتون ۳.۹ تا ۳.۱۱
- Docker (اختیاری، برای اجرای محلی با Dockerfile)
- یا فقط برای تست با Gradio:

```bash
pip install -r requirements.txt
python app.py
```

۲. اجرا روی Hugging Face Space

1. یک Space جدید با SDK Docker بسازید.
2. فایل‌های همین مخزن را در Space آپلود کنید یا به مخزن گیت‌هاب متصل کنید.
3. Hardware: CPU basic (رایگان) یا T4 medium (سریع).
4. برنامه به‌طور خودکار build و اجرا می‌شود.

۳. اجرا با Docker (محلی)

```bash
docker build -t quran-tts .
docker run -p 7860:7860 quran-tts
```

---

📖 نحوه استفاده

1. مرورگر را در آدرس Space (مثلاً https://huggingface.co/spaces/tetrashop/quran-tts) باز کنید.
2. در کادر بالا، متن آیه را با اعراب کامل وارد کنید (مثال: بِسْمِ ٱللَّٰهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ).
3. یک فایل صوتی از قاری مورد نظر (۶-۳۰ ثانیه، WAV/MP3، بدون نویز) بارگذاری کنید.
4. دکمه‌ی Submit را بزنید.
5. پس از چند ثانیه (GPU) یا چند دقیقه (CPU)، فایل صوتی تلاوت پخش می‌شود و قابل دانلود است.

---

🔌 استفاده به عنوان API

برای استفاده در ربات تلگرام، وب‌سایت و غیره، می‌توانید از API داخلی Gradio استفاده کنید.

فراخوانی با curl

```bash
curl -X POST "https://huggingface.co/spaces/tetrashop/quran-tts/api/predict" \
  -H "Authorization: Bearer YOUR_HF_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "data": [
      "بِسْمِ ٱللَّٰهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ",
      {"name": "audio.wav", "data": "BASE64_OF_AUDIO"}
    ]
  }' --output recited.wav
```

کتابخانه gradio_client (پایتون)

```python
from gradio_client import Client, file

client = Client("tetrashop/quran-tts", hf_token="hf_xxx")
status, output_path = client.predict(
    "بِسْمِ ٱللَّٰهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ",
    file("sample.wav"),
    api_name="/predict"
)
```

🐞 چالش‌ها و راه‌حل‌ها

۱. خطای Could not find a version that satisfies the requirement TTS

علت: نسخه‌ی پایتون ۳.۱۳ با TTS سازگار نیست.
راه‌حل: استفاده از Dockerfile با FROM python:3.11-slim.

۲. خطای مجوز Coqui (You must confirm...)

علت: مدل نیاز به تأیید CPML دارد و در محیط غیرتعاملی خطا می‌دهد.
راه‌حل: تنظیم متغیر محیطی COQUI_TTS_AGREED=1 در Dockerfile و استفاده از echo y | python app.py در CMD.

۳. خطای cannot import name 'BeamSearchScorer' from 'transformers'

علت: نسخه‌ی جدید transformers این کلاس را حذف کرده است.
راه‌حل: نصب نسخه‌ی مشخص transformers==4.36.2.

۴. خطای Weights only load failed (Unsupported global)

علت: PyTorch 2.6 به‌طور پیش‌فرض بارگذاری وزن‌ها را محدود کرده است.
راه‌حل: کاهش نسخه‌ی PyTorch به 2.5.1 و استفاده از نسخه‌ی CPU-only.

۵. خطای libcudart.so.13: cannot open shared object file

علت: torch و torchaudio نسخه‌ی CUDA روی CPU-only Space نصب شده‌اند.
راه‌حل: نصب صریح نسخه‌ی CPU از PyTorch با --index-url https://download.pytorch.org/whl/cpu.

۶. خطای got an unexpected keyword argument 'allow_flagging'

علت: حذف پارامتر allow_flagging در Gradio جدید.
راه‌حل: جایگزینی با flagging_mode="never".
