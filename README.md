# تلاوت قرآن با شبیه‌سازی صدا (Voice Cloning)

پروژه‌ای متن‌باز برای تولید تلاوت آیات قرآن با استفاده از **شبیه‌سازی صدا** (Voice Cloning).  
با فراهم کردن متن یک آیه (با اعراب کامل) و یک فایل صوتی کوتاه از یک قاری، می‌توان تلاوتی با همان ویژگی‌های صوتی دریافت کرد.

## ✨ ویژگی‌ها
- پشتیبانی از زبان عربی با اعراب‌گذاری (تجوید)
- شبیه‌سازی صدا تنها با ۶ تا ۳۰ ثانیه نمونه
- رابط کاربری ساده و زیبا با **Gradio**
- امکان اجرا روی CPU و GPU
- آماده‌ی دیپلوی روی **Hugging Face Spaces** (رایگان)

## 📦 نیازمندی‌ها
- پایتون ۳.۹ تا ۳.۱۱
- کتابخانه‌های `TTS`، `gradio`، `soundfile`، `torch`

## 🚀 اجرای سریع
1. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

2. اجرای برنامه:

```bash
python app.py
```

3. مرورگر را در آدرس http://localhost:7860 باز کنید.

☁️ اجرا روی Hugging Face Spaces

مخزن را فورک کنید یا فایل‌ها را در یک Space جدید با SDK Gradio آپلود کنید.
در صورت نیاز به GPU، Hardware را T4 medium انتخاب کنید.
